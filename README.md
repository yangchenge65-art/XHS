# 热点素材台

为短视频创作者准备的每日精选与关键词素材工作台。

## 当前版本：每日 4 + 3 + 2

- 每天精选 **4 条抖音、3 条小红书、2 条大众热门事件**；无依据时保留缺额，不凑数。
- 每条附具体内容、来源链接、推荐理由、开头建议。不满意点“换一条”：优先使用备选，仅替换这一条；备选不足才重新联网搜找。
- 每天北京时间 09:00 自动生成一次，文件保存在 `data/reports/real/YYYY-MM-DD.xlsx`；替换后更新。文件被 Excel 占用时仍保留数据库内容，可在网页重新导出。
- 页面读取、下载、已完成的今日稿件不会重新触发付费调用。自动任务失败后当天不循环扣费，配置完成后可以手动点击生成。
- 电脑必须开机、保持网络且程序在运行；休眠或关闭窗口后不会执行。启动时已过 09:00 会补做当天未尝试的任务。

### OpenAI API 方式

这是可选方式；**默认优先使用下文的 ChatGPT 订阅方式，不需要配置 API 计费**。

打开“账户与预算”，填写 API key 和每次联网请求的人民币预留上界，保存后检查 API 连接，再生成今日精选。

**ChatGPT 订阅额度不能用于 OpenAI API**。API 平台需单独开通计费，本程序不会购买或充值。Windows 使用当前用户 DPAPI 加密保存 key；不回显、不导出、不上传。其他系统使用 `HOTDESK_OPENAI_API_KEY` 与 `HOTDESK_GPT_COST_CNY` 环境变量。密钥仅发送到固定 `https://api.openai.com`，不支持在网页修改成未知代理地址。

此方式固定调用 Responses API `gpt-5.1`，启用 `web_search`，最多 3 次工具调用及 5000 输出 token。请求设置 `store=false`，但这不等于承诺供应商零数据留存。检查连接只验证模型访问，不验证真实联网效果。

仅采用实际搜索工具引用过的 URL，抖音/小红书分类要求平台域名，剔除时间缺失、过期和未来内容。来源时间及摘要由模型提取，需人工核实；公开网页索引不等于全站热榜、完整讨论量或个人账户推荐流。

继续使用每月 **30 元共享本地预留额度**，与原有接口共用。费用上界须包含 token、联网工具、汇率和价格差异，不提供未经核实的默认报价。失败和格式校验不通过的请求也保守预留；不自动退款。它不是供应商账单同步或消费硬限额，不能保证 30 元覆盖每天运行及无限换题。

### Windows 用户升级

先停止旧程序，将新版 ZIP 全部解压。把新版文件覆盖到原程序文件夹，**保留已有的 `data/`、`.venv/` 和用户自行配置的文件**，再运行 `Start.bat`。也可以将新版放入新文件夹；如需保留原历史，先停止旧程序再复制整个 `data/`，不要覆盖新产生的数据。加密 key 只适用于原 Windows 用户，换电脑需要重新配置。

### 推荐：ChatGPT 订阅 + 本机 Codex

1. 双击 `Connect-Codex.bat`，或在页面“账户与预算”中点击“连接 ChatGPT 订阅”。
2. 首次安装官方 `@openai/codex@0.163.0` 到项目 `.tools/`；缺少 Node.js 22+ 时尝试用 winget 安装官方 Node LTS，Windows 可能要求确认安装器权限。
3. 官方 Codex 打开浏览器，选择你的 ChatGPT 账户登录。不在本程序填写密码、会话 cookie 或订阅令牌。
4. 登录后回到页面，选择“ChatGPT 订阅 · 本机 Codex”，刷新状态，再点击“生成今日精选”。

使用 Codex 当前默认可用模型，**不保证是 GPT-5.1**。仅调用官方 CLI，程序不读取/复制其认证文件，不把订阅凭据用于 OpenAI API。确认 CLI 已以 ChatGPT 登录后才运行；不会自动切到付费 API。CLI 使用临时目录、只读沙箱，禁用 shell/多代理/code mode，忽略用户自定义工具配置，保留官方登录。仅接受已完成的检索事件与其中实际出现的 URL，不用模型记忆拼凑来源。

订阅额度和可用模型/工具由账户控制，不能保证所有计划或地区可用，也不能保证 9 条总能集齐。每次任务最多 4 分钟，本地每天最多 8 次新任务（包括失败），备选替换不新增任务。不主动购买加量额度；如果你在账户启用付费加量，费用由账户设置决定。这里的 30 元 API 预留余额不能衡量或限制订阅额度。

请勿安装来源不明的“订阅转 API”工具、提取 cookie/token 或关闭 TLS 验证。实际 Windows 登录、模型可用性和联网仍需在你自己的机器上验证。官方依据：[Codex 登录说明](https://github.com/openai/codex#using-codex-with-your-chatgpt-plan)。

## 启动

Windows 用户：下载发行 ZIP、全部解压后双击 `Start.bat`；首次安装需要联网，详情见 `Windows使用说明.txt`。包内不含密钥、数据库或 Linux 虚拟环境。Windows 启动脚本尚未在真实 Windows 上执行验证。

需要 Python 3.12。使用当前 checkout，无需新建 worktree。

```bash
cd /workspace/XHS
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

默认端口 8000，仅绑定本机。页面有三个入口：每日热点、关键词探索、数据与预算。开启“体验示例数据”后可完整体验采集、查询、平台筛选及 Excel 导出。示例均为虚构，独立存储，不会填充到真实结果；示例链接是搜索入口，不是原始事件链接。

## 原有榜单与关键词接口（独立可选）

尚未用付费密钥完成真实联调，也未购买任何服务。TikHub 是候选适配器，不代表已确认其价格、授权范围或数据质量。

服务器环境变量（查看 `.env.example`，不要将密钥提交到 Git；应用不会自动读取 `.env`）：

| 变量 | 用途 |
| --- | --- |
| `TIKHUB_API_KEY` | TikHub 的 API 密钥，仅发送至 api.tikhub.io |
| `HOTDESK_CALL_COST_CNY` | **每次 HTTP 请求的人民币费用上界**，覆盖汇率及接口价格差异；未配置或非正数时禁止付费请求 |
| `HOTDESK_XHS_HOT_FEED` | 独立的小红书热榜 HTTPS JSON feed，规范见下文；不会收到 TikHub 密钥 |
| `HOTDESK_DATA_DIR` | 数据目录，默认 `data`，需持久化 |
| `HOTDESK_SCHEDULE` | `1` 开启定时任务（默认），`0` 关闭 |
| `HOTDESK_HOST` / `PORT` | 绑定地址 / 端口，默认 127.0.0.1:8000 |

接口定义参考 [TikHub 官方 SDK](https://github.com/TikHub/TikHub-API-Python-SDK)，核对版本见 `docs/data-sources.md`：

- 抖音热榜：`GET /api/v1/douyin/web/fetch_hot_search_result`。
- 抖音关键词：`POST /api/v1/douyin/search/fetch_general_search_v1`，`publish_time=7`。
- 小红书关键词：`GET /api/v1/xiaohongshu/app_v2/search_notes`，`time_filter=一周内`。
- 小红书全站热榜：当前官方 SDK 未发现对应接口；必须接入经过验证的独立 feed，**不会用创作者灵感或推荐流冒充全站热榜**。

独立 feed 应无认证或通过平台支持的代理注入认证；URL 不应包含密钥。响应格式：

```json
{"items":[{"id":"topic-123","title":"真实热点关键词","content":"具体内容","url":"https://www.xiaohongshu.com/...","rank":1}]}
```

接口域名须在环境网络设置中放行。未知结构、失败和未配置均明确提示，不作为成功空结果缓存。

## 原有接口规则与覆盖范围

- 原有 `/api/collect` 仍可手动采集榜单；当前 `run.py` 的每日定时任务生成新版 4/3/2 精选，不会额外自动调用原有 TikHub 榜单接口。
- 保存近七个自然日的榜单视图，按持续出现天数与最近排名排序。按同平台标准化标题合并，保持不同平台的来源独立。不会声称语义相似话题已自动合并，也不把出现天数当作讨论量。
- 单次搜索合并本地近七天榜单记录和每个平台搜索第一页。相关内容按可验证发布时间筛选最近 168 小时，剔除缺失时间、旧闻和未来内容；不承诺完整覆盖。相关内容与历史热搜明确区分，历史榜单只能从开始采集后积累。
- 同关键词（忽略大小写、首尾空格）成功结果缓存 6 小时。部分成功仍可导出；失败不会作为成功缓存，重试可能再次请求已成功平台并占用额度。
- 原有关键词查询的开头钩子为本地规则模板；新版每日精选则由 GPT-5.1 生成建议。两种方式均需核实事实、语境与适用性，不保证留存率。
- 每月本地最高预留 ¥30；按上海时区换月，SQLite 事务避免并发超额。失败请求也保守预留费用，不自动退还、不自动充值。**这不是供应商的硬消费上限或账单同步**；配置费用不准确、其他应用共用密钥、供应商调价均可能导致实际费用不同，请同时设置供应商消费限额。未验证 30 元能覆盖两个平台全部需求。
- Excel 含热点关键词、具体内容、链接、平台、类型、时间、天数、筛选理由、钩子建议及采集说明；导出完整查询结果，网页平台/持续出现筛选仅影响页面。导出本身不发起付费请求；查询导出有效期 6 小时。

## 常驻部署

当前为单用户、单实例开发版。`run.py` 在后台线程执行定时任务，关闭进程后不会采集。云任务环境不等同于全天候服务器。

部署到你持有的持续运行主机：安装依赖，将项目工作目录设为 checkout，使用服务管理器运行 `.venv/bin/python run.py`，设置环境变量，持久化 `data/`，配置自动重启。每次启动查看 `/api/status`，点击采集并验证 Excel 的来源及时间。外部访问前需在反向代理添加身份验证及 HTTPS；不要直接将开发服务器暴露到公网。多实例调度、账号系统及付费云部署不在首版范围内。
