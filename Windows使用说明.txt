热点素材台 · Windows 安装与启动

1. 下载 ZIP 后，右键选择“全部解压缩”。不要在压缩包内直接运行。
2. 将文件夹放在你有写入权限的位置，例如桌面。不要放入 Program Files。
3. 双击 Start.bat。第一次会检查 Python、安装依赖，成功后自动打开浏览器。
   如果没有 Python，会尝试使用 Windows 自带的 winget 安装当前用户版 Python 3.12。
   如果 winget 不可用，会打开 Python 官方下载页；安装 Python 3.12 或更新版本后再双击 Start.bat。
4. 页面右上方打开“体验示例数据”，即可试用每日热点、关键词查询和 Excel 下载。
5. 下次使用仍双击 Start.bat；依赖未改变时不会重复安装。

Install.bat 用于单独安装或重新安装依赖，完成后再运行 Start.bat。
请保留命令窗口，按 Ctrl+C 停止服务。电脑关机、休眠或程序停止期间不会采集。
网页地址为 http://127.0.0.1:8000，仅能在这台电脑访问，不是公网网址。
程序及数据保存在解压目录，卸载时停止程序后删除该文件夹即可。
如果安装器额外安装了 Python，其为独立软件，需要时可在 Windows“已安装的应用”中卸载。

每日正式使用（4 条抖音 + 3 条小红书 + 2 条大众事件）：
推荐使用订阅：双击 Connect-Codex.bat，首次安装 Node.js（如缺少）与官方 Codex，浏览器打开后登录你的 ChatGPT 账户。
也可以在“账户与预算”中点击“连接 ChatGPT 订阅”，会打开同样的本机登录窗口。
不要在本程序填写 ChatGPT 密码；登录由官方 Codex 处理，本程序不读取或复制其登录凭据。
登录完成后回到页面，选择“ChatGPT 订阅 · 本机 Codex”，点“已登录，刷新状态”，再生成今日精选。
使用 Codex 当前默认可用模型，不保证是 GPT-5.1。需要你的订阅有可用 Codex 额度和联网工具权限。
不自动改用付费 API，不自动购买额外额度；如果账户已开启付费加量，其费用由你的账户设置控制。
每天最多 8 次新的 Codex 联网任务，失败也计数；备选素材替换不新增调用。每次最多等待 4 分钟。
如坚持指定 GPT-5.1，可以切换可选的 OpenAI API 模式，另开 API 计费；ChatGPT 订阅额度不能直接用于 API。
API 模式的 key 由 Windows 当前用户系统加密保存；需填写每次请求人民币预留上界，不会回显或上传。
来源不足时会保留缺额，不把虚构内容当作真实热点。GPT 搜索公开网页，不等于登录社交账户或完整平台热榜。
不满意时点击对应素材的“换一条”，不会重做其余内容；有备选时不新增联网调用。
每日北京时间 9 点自动生成 Excel，保存在 data\reports\real\日期.xlsx。电脑及程序必须保持运行。
关闭电脑、休眠或退出程序时不会执行；下次启动会补做当天未尝试的任务。
每月 30 元为付费 API 和其他付费接口的本地预留上限，不能衡量或限制订阅额度，不等同于实际账单上限。
不自动购买或充值，请勿在聊天中发送 API 密钥。

升级：先停止旧程序，再把新版文件覆盖进原文件夹，保留已有 data、.venv 和用户自己配置的文件，再运行 Start.bat。
原有关键词查询接口仍独立保留，需 TikHub 密钥及其费用配置；不影响新版 GPT 每日精选。

安装脚本仅在本次进程使用 PowerShell ExecutionPolicy Bypass，不修改系统执行策略。
依赖下载保持 HTTPS/TLS 验证，不关闭杀毒软件或系统防护；如果 Windows 提示拦截，先核对下载来源，不要直接关闭防护。

出现错误时：保留窗口，将报错文字或截图发来（遮住任何密钥），可以继续协助排查。

验证范围：服务端测试及浏览器流程已在 Linux 云环境运行，官方 Codex 0.163.0 已安装并检查命令帮助；Windows 脚本、你的订阅登录及真实联网尚未验证。
