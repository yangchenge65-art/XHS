# 热点素材台实施计划

目标：先交付可试用的平台，具体选题规则和内容效果在试用中调整。用户允许先实现，接口预算每月 30 元，不自动购买服务。

架构：Flask 页面/API、SQLite 历史与缓存、单实例后台定时任务、openpyxl 导出。密钥仅从环境读取。演示与真实数据库隔离。

1. 编写行为测试并确认缺失实现导致失败：每日重复采集、连续上榜、七天过滤、缓存、失败状态、跨月预算、Excel 公式与示例标识。
2. 实现存储、评分和服务。每日上海时间 9 点采集，失败不冒充成功，手动可重试；预算按每次请求的配置预留金额原子扣减。
3. 实现数据源适配：官方 SDK 定义验证过的 TikHub 抖音热榜/搜索、小红书搜索；小红书热榜使用可配置的标准 JSON feed。未配置必须提示。仅一页搜索，不宣称完整历史热搜。
4. 实现中文网页：每日热点、近七天关键词、预算与接入状态、Excel 下载、独立示例模式。
5. 运行全部测试和 HTTP/Excel 功能检查；保存依赖安装与启动说明。报告未完成的密钥接入、真实网络联调和常驻部署。

验收：示例流程可完整运行；未接入时真实页为空并说明原因；已保存的真实结果断网仍可查；不泄露密钥、不伪造热度、不把出现次数解释为讨论量。
