# 每日九条正式使用升级

需求：每天最多抖音 4 条、小红书 3 条、大众热门事件 2 条；GPT-5.1 联网搜找并整理，单条不满意后替换，Excel 只包含最终入选内容。沿用每月 30 元本地预留额度，不自动提高预算。账户类型已异步询问；ChatGPT 订阅不能作为第三方 OpenAI API 凭据。

最新确认：账户指 ChatGPT/OpenAI。用户不希望另开 API 计费，选择优先使用官方本机 Codex 的 ChatGPT 订阅登录，接受 Codex 当前支持的模型，不再要求固定 GPT-5.1。默认使用此方式，API 作为显式可选方式保留，不自动回退。新增 Windows 官方 CLI 安装/登录入口；不读认证文件或转用订阅令牌。每天本地最多 8 次新 Codex 任务，备选优先，超时4分钟。

实现顺序：
1. 先写行为测试：4/3/2 配额、持久化、跨类去重、单条替换不动其他条目、备选耗尽后的搜找、失败保留原稿、日切换、Excel 最终结果。
2. 独立 daily brief 表保存今日稿件、备选和排除项；不删除旧榜单/关键词数据库。读取和导出不触发付费操作。
3. OpenAI Responses API 固定模型 gpt-5.1 + web_search；要求引用源来自实际 web_search 返回的 URL，检查平台域名和发布时间；无证据不补齐配额，不宣称全部来自官方热榜。
4. 本机配置界面只接受 API key，不接受 ChatGPT/社交账户密码。Windows 通过当前用户 DPAPI 加密保存，其他系统仅支持环境变量。检查连接只验证模型访问，不能当作联网检索已验证。
5. 今日稿件每天 09:00 自动生成一次，并写出 Excel；单条替换后更新。电脑/进程必须持续运行。界面显示来源、不足配额、预算和密钥状态。
6. 运行自动化及浏览器检查，更新 Windows 说明，上传到此前授权的 GitHub 仓库供用户更新。没有实际密钥时不得声称已联通 OpenAI 或真实热点采集通过。
